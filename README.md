# 🎮 Emmy's Adventure Arcade

A colorful, kid-friendly arcade with **8 games and 96 levels**. The game runs entirely in your browser, with no account or installation required.

## Play online

Once GitHub Pages is enabled, play at:
https://mitchaaron.github.io/emmys-adventure-arcade/

## Games

- ⚽ Soccer — kick past a moving goalie (a block requires the ball to touch the glove)
- 🏀 Basketball — arc shots into the hoop
- 💅 Rainbow Nail Salon — colors, patterns, glitter, gems, and style challenges
- 🔷 Shapes — find shapes and solve increasingly tricky rounds
- 🔢 Numbers — counting challenges
- 😊 Feelings — recognize expressions
- 💀 Skeletons — dancing skeletons and draw-your-own character
- 🕵️ Animal Explorer — find animals in different habitats

The game saves progress in local browser storage when available. The main playable file is [index.html](./index.html).

## Turn on the website (one-time)

1. Open [Settings → Pages](https://github.com/mitchaaron/emmys-adventure-arcade/settings/pages).
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Choose **main** and **/(root)**, then click **Save**.
4. Open the game URL above once GitHub reports it published.

Future changes to `main/index.html` will automatically update the website.
